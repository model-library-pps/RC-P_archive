**Name**\
RC-P

**Program type**\
Simple simulation model

**Available since**\
Mon, 12/13/2010 - 12:00

**Description**\
RC-P is a simple model to calculate the long-term effect of fertiliser phosphorus application(s) on crop P uptake and yield. The input data are mainly derived from  a one-year P-fertiliser trial on a representative crop and soil combination 

References with more information about the RC-P model and applications:

Wolf, J., C.T. de Wit, B.H. Janssen and D.J. Lathwell. 1987. Modeling long-term crop response to fertilizer phosphorus: I. The model. Agron. J. 79: 445-451.

Janssen, B.H., D.J. Lathwell and J. Wolf. 1987. Modeling long-term crop response to fertilizer phosphorus. II. Comparison with field results. Agron. J.: 452-458
